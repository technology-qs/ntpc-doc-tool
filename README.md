# 新北市公文小工具

自動幫新北市公文系統（SPEED）下載的公文本文與附件統一改檔名、歸到同一個資料夾，不用再手動一個個改檔名。

## 功能

- 點「檔案處理 → 匯出PDF」下載本文時，自動改成好辨識的檔名
- 下載附件時，自動歸到跟本文同一個資料夾
- 右鍵選單的「下載所有附件」（.zip）會自動解壓縮成個別檔案，一樣套用同一套命名規則
- 「查詢以往歷年公文」清單頁選取某一筆、下載電子檔案時，也會自動套用命名規則

## 安裝方式

1. 下載（或 `git clone`）這個資料夾到你的電腦
2. Chrome 網址列輸入 `chrome://extensions`
3. 右上角開啟「開發人員模式」
4. 點「載入未封裝項目」，選取這個資料夾
5. 安裝完成後，工具列會出現擴充功能圖示

## 使用方式

安裝好之後不用改變平常的操作習慣：

1. 開啟一份公文，照平常點「檔案處理 → 匯出PDF」或附件的下載圖示
2. Chrome 下載下來的檔案會自動改好名字、歸到資料夾裡，不需要任何額外操作
3. 想確認目前抓到的資料夾名稱/檔名，可以點一下工具列的擴充功能圖示看預覽

## 檔名規則

- 資料夾：`新北市公文/{西元年月日}_{主旨}/`
- 本文（匯出PDF）：`{發文字號或公文文號}_{主旨}.pdf`
- 附件：`{發文字號或公文文號}_附件N.副檔名`（依下載順序編號，例如 `台展字第11507000295號_附件1.pdf`；沒有發文字號時改用公文文號）

## 常見問題

- **改版過 manifest.json 不會自動生效**：到 `chrome://extensions` 這個擴充功能卡片上點一下「重新載入」。
- **檔名跑掉了**：請依照下面「回報問題」的步驟回報給開發者協助排查。

## 回報問題

檔名抓錯、資料夾跑掉，或任何操作上的問題，請到 GitHub 開一個 Issue：

1. 開啟 [https://github.com/technology-qs/ntpc-doc-tool/issues](https://github.com/technology-qs/ntpc-doc-tool/issues)
2. 點右上角綠色的「New issue」
3. 標題簡單描述問題（例如：「附件檔名變成本文主旨」）
4. 內文請盡量附上：
   - 是在哪個頁面發生的（公文編輯頁面、查詢以往歷年公文清單頁…）
   - 預期的檔名／資料夾名稱，跟實際跑出來的檔名／資料夾名稱
   - Console 訊息或截圖：到 `chrome://extensions` 找到這個擴充功能，點「service worker」打開除錯主控台，或在公文頁面按 `F12` 開啟瀏覽器主控台，把裡面 `[公文小工具]` 開頭的那幾行訊息複製貼上（或截圖）
5. 點「Submit new issue」送出

沒有 GitHub 帳號的話，直接把上面第 4 點的內容截圖後傳給開發者也可以。
